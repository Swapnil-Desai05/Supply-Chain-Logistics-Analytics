Supply Chain & Logistics Analytics Dashboard – Power BI

Project Overview:
This project focuses on analyzing supply chain and logistics operations using Power BI, PostgreSQL, SQL, DAX, Power Query, and Excel. The dashboard provides business insights into inventory levels, warehouse performance, supplier operations, stock availability, discrepancies, and operational risks.

Key Analysis : 
  -Inventory Stock & Stock Value
  - Inventory Turnover
  -Fill Rate
  -Inventory Aging
  -Stockout & Overstock Analysis
  -Slow-Moving Inventory
  -Warehouse Performance
  -Supplier Performance
  -Inventory Discrepancy Analysis
  -Validation Issues
  -Operational Risk Analysis
  -KPI Monitoring

Tools & Technologies :
  Power BI – Dashboard & visualization
  SQL / PostgreSQL – Data extraction and analysis
  DAX – Measures and KPI calculations
  Power Query – Data cleaning and transformation
  Excel – Data preparation and analysis
